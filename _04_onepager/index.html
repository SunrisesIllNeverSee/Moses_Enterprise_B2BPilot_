Deployment

Three deployment levels. Match the data to the question.

Level 1 · Canonical Telemetry

Token counts only, no prompt content. Best for Baseline, Capability Distribution, Adoption, Team Comparison, Monitor.

Level 2 · API Enriched

Adds timestamps, sessions, model/tool/agent data. Best for Training Evaluation, Model/Tool Evaluation, Agent Adoption, Experiments.

Level 3 · Integrated / Governed

Continuous measurement, customer-defined thresholds, governed state. Best for production infrastructure.
