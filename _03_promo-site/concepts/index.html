Canonical Metrics

The five.

The MO§ES™ evaluation framework defines five canonical derived metrics computed from four content-free token primitives. Each metric captures a different dimension of AI operator performance — output efficiency, context reuse, signal quality, context building, and overall development. Together they form a complete picture of how a human operates an AI system, without ever reading a single prompt or output.

CANONICAL
Yield

O / (I + O + R + W) — productive output share of total token flow. Measures output efficiency.
CANONICAL
Leverage

(R + W) / I — context reuse and building relative to new input. Measures context efficiency.
CANONICAL
Token SNR

Signal-to-noise ratio in AI operator token flow. Measures output quality and precision.
CANONICAL
Construction

W / R — ratio of new context built to context reused. Measures context architecture skill.
DEVELOPMENTAL
Composite Score

AI Operator Development Index — 0-100, weighted composite. DEVELOPMENTAL, not punitive.
Supporting Concepts

Framework definitions.

Beyond the five canonical metrics, the MO§ES™ framework includes diagnostic concepts for identifying performance patterns, reference populations for benchmarking, experimental methods for testing interventions, and governance labels that ensure measurement is used developmentally, not punitively.

DIAGNOSTIC
Divergence

Usage-operation divergence — identifies operators whose usage volume doesn't match performance.
REFERENCE
Benchmark

13 benchmark classes with selection algorithm for fair comparison.
EXPERIMENTAL
Intervention

Targeted changes with pre/post re-measurement. Results labeled ASSOCIATION, not causation.
PRIMITIVE
Canonical Telemetry

INPUT, OUTPUT, CACHE READ, CACHE WRITE — content-free, no prompt text, no PII.
GOVERNANCE
Governance

DEVELOPMENTAL/HYPOTHESIS/ASSOCIATION labels, no punitive use, no leaderboard ranking.

How the metrics connect

From primitives to decisions.

The four token primitives (I, O, R, W) flow through the five canonical metrics, which feed into diagnostics, benchmarks, and intervention testing. Every metric connects to a recommended action — not just a number on a dashboard. Low Yield means context structuring coaching. Low Leverage means a context caching workshop. High divergence means a workflow review. Every measurement translates to a developmental recommendation.
