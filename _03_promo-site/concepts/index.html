Canonical metric definitions.

The five canonical derived metrics and supporting concepts that form the MO§ES™ evaluation framework. Each concept page provides the formula, interpretation, and governance label.

Canonical Metrics

The five.

CANONICAL
Yield

O / (I + O + R + W) — productive output share of total token flow.
CANONICAL
Leverage

(R + W) / I — context reuse and building relative to new input.
CANONICAL
Token SNR

Signal-to-noise ratio in AI operator token flow.
CANONICAL
Construction

W / R — ratio of new context built to context reused.
DEVELOPMENTAL
Composite Score

AI Operator Development Index — 0-100, weighted composite. DEVELOPMENTAL.
