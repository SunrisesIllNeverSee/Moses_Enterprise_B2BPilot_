Common Terms

What's true across all three.

  • Content-free. No prompt text, no output text, no conversation content. Four token counts plus structural signals.
  • Five canonical metrics. Yield, Leverage, Token SNR, Log Leverage, Construction. Derived from the same four token numbers.
  • No leaderboards. Operators are measured by behavior, not ranked by name. No punitive labels.
  • Evidence labeled honestly. ASSOCIATION by default. CAUSATION only when a controlled experiment supports it.
  • Developmental, not personnel. Composite scores route coaching and intervention, not hiring decisions.
  • Privacy by design. Aligns with GDPR, SOC 2, and enterprise data governance.
