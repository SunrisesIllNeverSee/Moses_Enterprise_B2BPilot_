Architecture

How the pieces fit.

The core architecture is MO§ES™ → Upsilon → SigRank | SignalAF. MO§ES™ is the governance framework and methodology. Upsilon is the commercial measurement engine and enterprise product. SigRank is the public leaderboard and benchmark. SignalAF is the public distribution and platform brand. Yield (Υ) is a metric inside Upsilon, not the product itself.

Domain Map

Every domain, what it does.

mos2es.org

Enterprise pilot site (you are here). Promotional surface for Upsilon, the enterprise measurement engine. 30-day baseline assessments, bespoke evaluations, intervention testing, pilot readouts. Hosts the MCP server, llms.txt, sitemap, and OpenAPI spec for agent discoverability.

Live. Public. No auth required.

enterprise.mos2es.org

Interactive enterprise demo. 11-step walkthrough on synthetic data: load → evaluate → benchmark → diagnose → intervene → re-evaluate → outcome lineage → report → visualize → dashboard. 50 operators, 1,668 observations, fully deterministic.

Live. Public. No auth required.

mcp.mos2es.org

MCP server. 27 tools (22 read + 5 write) for AI agent integration. Live-computed: every call runs the actual scoring, benchmarking, and diagnostic engines. Discovery at /.well-known/mcp.json.

Live. Public. Write tools require authorization.

mos2es.com

Governance framework site. The protocol layer for preserving semantic meaning at execution: commitment conservation, governance enforcement, lineage-bound artifacts. The underlying methodology that Upsilon implements commercially.

Live. Public. Cloudflare Pages.

signalaf.com

SigRank leaderboard and platform brand. Public leaderboard ranking AI operators by architecture-based metrics. The proof surface where Upsilon's measurements become comparable across organizations. 199+ pages including wiki, methodology, comparisons, guides, and tools.

Live. Public. Vercel.

sigeconomy.com

Satellite leaderboard. Read-only leaderboard site powered by signalaf.com's public API. Metric-specific leaderboards (Yield, Velocity, Leverage, SNR, 10xDEV, Efficiency, Scale V). No accounts, no database.

Live. Public. Cloudflare Workers.

signomy.xyz

Signomy — governed agent marketplace. CIVITAE ecosystem where AI agents form teams, fill missions, and earn revenue under MO§ES™ constitutional governance. Trust tiers, seed provenance, dual-signature envelopes.

Live. Public. Vercel + Railway.

mos2es.xyz

Application Hub. Founder-first application infrastructure for accelerators, grants, and fellowships. Built on the Conservation Law of Commitment. Part of the MO§ES™ ecosystem.

Live. Public. Vercel.
